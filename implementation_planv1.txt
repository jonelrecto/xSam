Email gotcha for an open prototype: most email providers (Resend included) only let you send to arbitrary addresses once you've verified a sending domain. Without one, verification emails won't reach students. That's why I added the REQUIRE_EMAIL_VERIFICATION flag: keep it false while you build, and switch it on once you have a domain (the cheap TLD idea from earlier works). Check your provider's current free-tier limits before relying on them.

import { Resend } from "resend";
const resend = process.env.RESEND_API_KEY ? new Resend(process.env.RESEND_API_KEY) : null;

export async function sendEmail(to: string, subject: string, url: string) {
  if (!resend) return console.log(`[email:dev] ${subject} -> ${to}\n${url}`);
  await resend.emails.send({
    from: "SEPE <no-reply@yourdomain.com>", to, subject,
    html: `<p><a href="${url}">${subject}</a></p>`,
  });
}
2. Server auth config: src/lib/auth.ts
ts
import { betterAuth } from "better-auth";
import { drizzleAdapter } from "better-auth/adapters/drizzle";
import { nextCookies } from "better-auth/next-js";
import { db } from "@/lib/db";
import * as schema from "@/lib/db/schema";
import { sendEmail } from "@/lib/email";

const SELF_SIGNUP_ROLES = ["student", "teacher"];

export const auth = betterAuth({
  database: drizzleAdapter(db, { provider: "pg", schema }),

  emailAndPassword: {
    enabled: true,
    minPasswordLength: 8,
    requireEmailVerification: process.env.REQUIRE_EMAIL_VERIFICATION === "true",
    sendResetPassword: async ({ user, url }) =>
      sendEmail(user.email, "Reset your password", url),
  },
  emailVerification: {
    sendOnSignUp: true,
    sendVerificationEmail: async ({ user, url }) =>
      sendEmail(user.email, "Verify your email", url),
  },

  user: {
    additionalFields: {
      role: { type: "string", required: false, defaultValue: "student", input: true },
    },
  },

  databaseHooks: {
    user: {
      create: {
        // only student/teacher can be self-selected; anything else becomes student
        before: async (user) => {
          const role = SELF_SIGNUP_ROLES.includes(user.role as string) ? user.role : "student";
          return { data: { ...user, role } };
        },
      },
      update: {
        // role can never be changed through the auth API
        before: async (user) => {
          const { role, ...rest } = user as Record<string, unknown>;
          return { data: rest };
        },
      },
    },
  },

  rateLimit: { enabled: true, window: 60, max: 30 },

  // socialProviders: { google: { clientId: ..., clientSecret: ... } }, // later
  plugins: [nextCookies()], // keep this last
});
Two notes on this file:

The nextCookies() plugin needs to be the last plugin in the array so cookies set from Server Actions work. 
next-safe-action
The update.before hook matters. Because role is an input field, without it a logged-in student could call updateUser({ role: "admin" }) themselves. Hook signatures can vary between Better Auth versions, so confirm this file against the current docs and run the security tests in section 7. This is the part where a small mistake becomes a security hole.
Better Auth handles password hashing itself, so you don't need to add an argon2 package. Admin accounts are created by updating the role column directly in the database (or with a small seed script), which doesn't go through these hooks.

export async function requireRole(allowed: Role[]) {
  const session = await getSession();
  if (!session) redirect("/login");
  const role = session.user.role as Role;
  if (!allowed.includes(role)) redirect(homeFor(role));

}

3. The CSV validator: src/lib/csv/parse-exam-csv.ts
The validation logic is a pure function (validateRows), so you can unit test it without files.

ts
import Papa from "papaparse";
import { draftQuestionSchema, type DraftQuestion } from "@/lib/schemas/exam";

export const MAX_ROWS = 200;
export const MAX_BYTES = 1_000_000;
const REQUIRED_COLUMNS = ["type", "prompt", "answer"];

export type CsvIssue = { row: number | null; column?: string; message: string; severity: "error" | "warning" };
export type CsvParseResult = { questions: DraftQuestion[]; issues: CsvIssue[]; totalRows: number; invalidRows: number };

const TYPE_ALIASES: Record<string, DraftQuestion["type"]> = {
  multiple_choice: "multiple_choice", mcq: "multiple_choice", mc: "multiple_choice",
  true_false: "true_false", tf: "true_false", "true/false": "true_false",
  identification: "identification", id: "identification",
  essay: "essay",
};

const fileError = (message: string): CsvParseResult => ({
  questions: [], totalRows: 0, invalidRows: 0,
  issues: [{ row: null, message, severity: "error" }],
});

export function parseExamCsv(file: File): Promise<CsvParseResult> {
  return new Promise((resolve) => {
    if (file.size > MAX_BYTES) return resolve(fileError("File is larger than 1 MB"));
    Papa.parse<Record<string, string>>(file, {
      header: true,
      skipEmptyLines: "greedy",
      transformHeader: (h) => h.trim().toLowerCase(),
      complete: (res) => resolve(validateRows(res.data, res.meta.fields ?? [])),
      error: (err) => resolve(fileError(err.message)),
    });
  });
}

export function validateRows(rows: Record<string, string>[], fields: string[]): CsvParseResult {
  const missing = REQUIRED_COLUMNS.filter((c) => !fields.includes(c));
  if (missing.length) return fileError(`Missing column(s): ${missing.join(", ")}. Download the template to see the expected headers.`);
  if (rows.length === 0) return fileError("The file has no question rows");
  if (rows.length > MAX_ROWS) return fileError(`Too many rows (max ${MAX_ROWS})`);

  const issues: CsvIssue[] = [];
  const good: DraftQuestion[] = [];
  const seenOrders = new Set<number>();
  let invalidRows = 0;

  rows.forEach((raw, i) => {
    const row = i + 2; // line 1 is the header
    const rowIssues: CsvIssue[] = [];
    const err = (column: string, message: string) => rowIssues.push({ row, column, message, severity: "error" });
    const warn = (column: string, message: string) => rowIssues.push({ row, column, message, severity: "warning" });
    const cell = (k: string) => (raw[k] ?? "").trim();

    const type = TYPE_ALIASES[cell("type").toLowerCase()];
    if (!type) err("type", `"${cell("type")}" is not a valid type`);

    const prompt = cell("prompt");
    if (!prompt) err("prompt", "Question text is required");

    let order = i + 1;
    if (cell("order")) {
      const n = Number(cell("order"));
      if (!Number.isInteger(n) || n < 1) err("order", "Must be a whole number of 1 or more");
      else if (seenOrders.has(n)) err("order", `Duplicate order ${n}`);
      else { order = n; seenOrders.add(n); }
    }

    let points = 1;
    if (cell("points")) {
      const p = Number(cell("points"));
      if (!(p > 0 && p <= 100)) err("points", "Must be a number greater than 0 and up to 100");
      else points = p;
    }

    let options: string[] | null = null;
    let answers: string[] = [];

    if (type === "multiple_choice") {
      const opts = ["opt_a", "opt_b", "opt_c", "opt_d"].map(cell);
      const filled = opts.filter(Boolean);
      if (filled.length < 2) err("opt_a", "At least 2 options are required");
      else if (new Set(filled.map((o) => o.toLowerCase())).size !== filled.length)
        err("opt_a", "Options must be different from each other");
      const letter = cell("answer").toUpperCase();
      const idx = "ABCD".indexOf(letter);
      if (letter.length !== 1 || idx === -1 || !opts[idx])
        err("answer", `"${cell("answer")}" must be A–D and point to a filled option`);
      else answers = [opts[idx]];
      options = filled;
    } else if (type === "true_false") {
      const a = cell("answer").toLowerCase();
      if (a !== "true" && a !== "false") err("answer", 'Must be "true" or "false"');
      else answers = [a];
    } else if (type === "identification") {
      answers = cell("answer").split("|").map((s) => s.trim()).filter(Boolean);
      if (answers.length === 0) err("answer", "At least one accepted answer is required");
    } else if (type === "essay" && cell("answer")) {
      warn("answer", "Essay answers are ignored (essays are graded manually)");
    }

    if (rowIssues.some((r) => r.severity === "error")) {
      invalidRows++; issues.push(...rowIssues); return;
    }

    const candidate = {
      tempId: crypto.randomUUID(), order, type, prompt, options, answers,
      answerSource: type === "essay" ? "missing" : "provided",
      points, warnings: [], confirmed: false,
    };
    const parsed = draftQuestionSchema.safeParse(candidate);
    if (!parsed.success) {
      invalidRows++;
      issues.push({ row, message: parsed.error.issues[0].message, severity: "error" });
      return;
    }
    issues.push(...rowIssues);
    good.push(parsed.data);
  });

  good.sort((a, b) => a.order - b.order).forEach((q, i) => (q.order = i + 1));
  return { questions: good, issues, totalRows: rows.length, invalidRows };
}
A few design choices here:

The parser reports every problem in one pass, so the teacher fixes the file once instead of re-uploading repeatedly.
Multiple-choice answers are stored as the option text, not the letter. That keeps them consistent with the shared publishableQuestionSchema, and it survives option shuffling later.
Essays get answerSource: "missing", and the publish gate already exempts essays from needing a key.
This is convenience validation in the browser. The server re-validates with the same schemas when saving in milestone 4.
4. Shared draft store: src/hooks/use-draft-store.ts
ts
import { create } from "zustand";
import type { DraftQuestion } from "@/lib/schemas/exam";

type Source = "csv" | "pdf" | "manual";
type DraftState = {
  examId: string | null;
  questions: DraftQuestion[];
  source: Source | null;
  load: (examId: string, incoming: DraftQuestion[], mode: "replace" | "append", source: Source) => void;
  clear: () => void;
};

export const useDraftStore = create<DraftState>((set) => ({
  examId: null, questions: [], source: null,
  load: (examId, incoming, mode, source) =>
    set((s) => {
      const base = s.examId === examId && mode === "append" ? s.questions : [];
      const merged = [...base, ...incoming].map((q, i) => ({ ...q, order: i + 1 }));
      return { examId, questions: merged, source };
    }),
  clear: () => set({ examId: null, questions: [], source: null }),
}));

0. Corrections to earlier milestones
The draft schema was too strict for autosave. draftQuestionSchema required options.min(2) and a non-empty prompt. A brand-new "Add question" card would fail validation and autosave would reject it. Split it into a lenient schema for saving drafts and a strict one for publishing. Replace both in src/lib/schemas/exam.ts:
ts
export const draftQuestionSchema = z.object({
  tempId: z.string(),
  order: z.number().int().positive(),
  type: questionType,
  prompt: z.string().max(5000),
  options: z.array(z.string().max(500)).max(6).nullable(),
  answers: z.array(z.string().max(500)).max(20),
  answerSource: z.enum(["provided", "ai_inferred", "missing"]),
  points: z.number().positive().max(100),
  sourcePage: z.number().int().positive().optional(),
  warnings: z.array(z.string().max(300)).max(20).default([]),
  confirmed: z.boolean().default(false),
});
export type DraftQuestion = z.infer<typeof draftQuestionSchema>;
export const saveDraftSchema = z.array(draftQuestionSchema).max(200);

// strict: used by the publish gate and shown live on each card
export const publishableQuestionSchema = draftQuestionSchema.superRefine((q, ctx) => {
  const fail = (message: string, path: string[] = ["answers"]) =>
    ctx.addIssue({ code: "custom", message, path });

  if (!q.prompt.trim()) fail("Question text is required", ["prompt"]);
  if (q.type !== "essay" && !q.confirmed) fail("Answer not confirmed", ["confirmed"]);

  switch (q.type) {
    case "multiple_choice": {
      const opts = (q.options ?? []).map((o) => o.trim());
      if (opts.length < 2 || opts.some((o) => !o)) return fail("Need at least 2 non-empty options", ["options"]);
      if (new Set(opts.map((o) => o.toLowerCase())).size !== opts.length) return fail("Options must be different", ["options"]);
      if (q.answers.length !== 1 || !opts.includes(q.answers[0].trim())) fail("Pick the correct option");
      break;
    }
    case "true_false":
      if (q.answers.length !== 1 || !["true", "false"].includes(q.answers[0].toLowerCase())) fail("Choose true or false");
      break;
    case "identification":
      if (!q.answers.some((a) => a.trim())) fail("Add at least one accepted answer");
      break;
    case "essay":
      break;
  }
});

2. Server actions: src/app/actions/exam.ts
ts
"use server";
import { and, asc, eq, sql } from "drizzle-orm";
import { db } from "@/lib/db";
import { exams, questions } from "@/lib/db/schema";
import { getOwnedExam } from "@/lib/exams";
import { saveDraftSchema, publishableQuestionSchema } from "@/lib/schemas/exam";

export async function saveDraft(examId: string, baseVersion: number, input: unknown) {
  const exam = await getOwnedExam(examId);
  if (exam.status !== "draft") return { ok: false, code: "LOCKED" } as const;

  const parsed = saveDraftSchema.safeParse(input);
  if (!parsed.success) return { ok: false, code: "INVALID" } as const;

  // optimistic lock: only save if nobody saved since this client loaded
  const bumped = await db.update(exams)
    .set({ draftVersion: sql`${exams.draftVersion} + 1` })
    .where(and(eq(exams.id, examId), eq(exams.draftVersion, baseVersion), eq(exams.status, "draft")))
    .returning({ v: exams.draftVersion });
  if (bumped.length === 0) return { ok: false, code: "CONFLICT" } as const;

  // server ignores client tempIds and generates its own row ids
  const rows = parsed.data.map((q, i) => ({
    examId, orderIndex: i + 1, type: q.type, prompt: q.prompt,
    options: q.options, answers: q.answers, answerSource: q.answerSource,
    confirmed: q.confirmed, points: String(q.points),
    sourcePage: q.sourcePage ?? null, warnings: q.warnings,
  }));
  const del = db.delete(questions).where(eq(questions.examId, examId));
  if (rows.length) await db.batch([del, db.insert(questions).values(rows)]);
  else await del;

  return { ok: true, version: bumped[0].v } as const;
}

export async function getDraftVersion(examId: string) {
  return (await getOwnedExam(examId)).draftVersion;
}

export async function publishExam(examId: string) {
  const exam = await getOwnedExam(examId);
  if (exam.status !== "draft") return { ok: false, issues: ["This exam is already published"] } as const;

  const rows = await db.select().from(questions)
    .where(eq(questions.examId, examId)).orderBy(asc(questions.orderIndex));

  const issues: string[] = [];
  if (rows.length === 0) issues.push("Add at least one question");
  for (const r of rows) {
    const res = publishableQuestionSchema.safeParse({
      tempId: r.id, order: r.orderIndex, type: r.type, prompt: r.prompt,
      options: r.options, answers: r.answers, answerSource: r.answerSource,
      points: Number(r.points), warnings: r.warnings, confirmed: r.confirmed,
    });
    if (!res.success) issues.push(`Question ${r.orderIndex}: ${res.error.issues[0].message}`);
  }
  if (exam.scheduledEnd && exam.scheduledEnd <= new Date()) issues.push("Scheduled end is in the past");
  if (issues.length) return { ok: false, issues } as const;

  await db.update(exams).set({ status: "published" })
    .where(and(eq(exams.id, examId), eq(exams.status, "draft")));
  return { ok: true } as const;
}
Why the details matter:

Publish validates what's in the database, not what the browser claims, so the client must flush its autosave first.
Once an exam leaves draft, saveDraft refuses to touch it. This freezes the answer key for the exam's whole life. Every later milestone relies on that.
Replace-all is safe here. No student answers reference draft questions yet, so regenerating row ids on each save is fine, and it avoids letting a client-supplied id collide with another teacher's rows.
The Neon HTTP driver doesn't support interactive transactions, which is why the delete and insert go through db.batch(). The version bump is a separate step before it, so the pair isn't fully atomic. If the batch fails after the bump, the client's next save reports a conflict, and the dialog below lets the teacher overwrite with their version. That's an acceptable trade for a prototype. Confirm db.batch against the Drizzle docs for your installed version.
3. Draft store: src/hooks/use-draft-store.ts
Replace the Milestone 3 store. The revision and savedRevision counters let autosave know whether edits happened while a save was in flight.

ts
import { create } from "zustand";
import type { DraftQuestion } from "@/lib/schemas/exam";

type QType = DraftQuestion["type"];
const renumber = (qs: DraftQuestion[]) => qs.map((q, i) => ({ ...q, order: i + 1 }));

export const blankQuestion = (type: QType): DraftQuestion => ({
  tempId: crypto.randomUUID(), order: 0, type, prompt: "",
  options: type === "multiple_choice" ? ["", ""] : null,
  answers: [], answerSource: type === "essay" ? "missing" : "provided",
  points: 1, warnings: [], confirmed: false,
});

type State = {
  examId: string | null; hydrated: boolean; version: number;
  revision: number; savedRevision: number; questions: DraftQuestion[];
  init: (examId: string, qs: DraftQuestion[], version: number) => void;
  load: (qs: DraftQuestion[], mode: "replace" | "append") => void;
  add: (type: QType) => void;
  remove: (id: string) => void;
  duplicate: (id: string) => void;
  move: (from: number, to: number) => void;
  patch: (id: string, p: Partial<DraftQuestion>) => void;
  setType: (id: string, type: QType) => void;
  setOption: (id: string, idx: number, text: string) => void;
  addOption: (id: string) => void;
  removeOption: (id: string, idx: number) => void;
  setAnswers: (id: string, answers: string[]) => void;   // teacher chose it = confirmed
  setConfirmed: (id: string, v: boolean) => void;
  confirmAllProvided: () => void;
  markSaved: (version: number, revision: number) => void;
};

export const useDraftStore = create<State>((set) => {
  const mutate = (fn: (qs: DraftQuestion[]) => DraftQuestion[]) =>
    set((s) => ({ questions: renumber(fn(s.questions)), revision: s.revision + 1 }));
  const mapQ = (id: string, fn: (q: DraftQuestion) => DraftQuestion) =>
    mutate((qs) => qs.map((q) => (q.tempId === id ? fn(q) : q)));

  return {
    examId: null, hydrated: false, version: 0, revision: 0, savedRevision: 0, questions: [],
    init: (examId, qs, version) =>
      set({ examId, hydrated: true, version, questions: renumber(qs), revision: 0, savedRevision: 0 }),
    load: (qs, mode) => mutate((cur) => (mode === "append" ? [...cur, ...qs] : qs)),
    add: (type) => mutate((qs) => [...qs, blankQuestion(type)]),
    remove: (id) => mutate((qs) => qs.filter((q) => q.tempId !== id)),
    duplicate: (id) => mutate((qs) => {
      const i = qs.findIndex((q) => q.tempId === id);
      if (i < 0) return qs;
      const copy = { ...structuredClone(qs[i]), tempId: crypto.randomUUID() };
      return [...qs.slice(0, i + 1), copy, ...qs.slice(i + 1)];
    }),
    move: (from, to) => mutate((qs) => {
      if (to < 0 || to >= qs.length) return qs;
      const next = [...qs]; const [m] = next.splice(from, 1); next.splice(to, 0, m); return next;
    }),
    patch: (id, p) => mapQ(id, (q) => ({ ...q, ...p })),
    setType: (id, type) => mapQ(id, (q) => ({
      ...blankQuestion(type), tempId: q.tempId, prompt: q.prompt, points: q.points,
    })),
    setOption: (id, idx, text) => mapQ(id, (q) => {
      const options = [...(q.options ?? [])];
      const old = options[idx]; options[idx] = text;
      const answers = q.answers[0] === old && old !== "" ? [text] : q.answers; // keep key in sync
      return { ...q, options, answers };
    }),
    addOption: (id) => mapQ(id, (q) =>
      (q.options?.length ?? 0) >= 6 ? q : { ...q, options: [...(q.options ?? []), ""] }),
    removeOption: (id, idx) => mapQ(id, (q) => {
      const options = [...(q.options ?? [])];
      if (options.length <= 2) return q;
      const [removed] = options.splice(idx, 1);
      const wasKey = q.answers[0] === removed;
      return { ...q, options, answers: wasKey ? [] : q.answers, confirmed: wasKey ? false : q.confirmed };
    }),
    setAnswers: (id, answers) => mapQ(id, (q) => ({
      ...q, answers, answerSource: "provided", confirmed: answers.length > 0,
    })),
    setConfirmed: (id, v) => mapQ(id, (q) => ({ ...q, confirmed: v })),
    confirmAllProvided: () => mutate((qs) => qs.map((q) =>
      q.answerSource === "provided" && q.answers.length > 0 ? { ...q, confirmed: true } : q)),
    markSaved: (version, revision) => set({ version, savedRevision: revision }),
  };
});
Design rules baked in here:

Choosing an answer yourself counts as confirming it, and it switches the source to provided.
"Confirm all provided answers" only touches answers that came from the CSV or the teacher. AI-guessed ones still need an individual click. This is the safety property from the plan.
Renaming an option keeps the answer key pointing at it, and removing the correct option clears the key and un-confirms it.
Changing the question type resets options and answers, but keeps the prompt and points.
4. Autosave: src/hooks/use-autosave.ts
ts
"use client";
import { useCallback, useEffect, useRef, useState } from "react";
import { saveDraft } from "@/app/actions/exam";
import { useDraftStore } from "./use-draft-store";

export type SaveStatus = "saved" | "dirty" | "saving" | "error" | "conflict" | "locked";

export function useAutosave(examId: string) {
  const [status, setStatus] = useState<SaveStatus>("saved");
  const statusRef = useRef(status); statusRef.current = status;
  const inFlight = useRef<Promise<void> | null>(null);

  const save = useCallback(async () => {
    if (inFlight.current) return inFlight.current;
    inFlight.current = (async () => {
      setStatus("saving");
      const { questions, version, revision } = useDraftStore.getState();
      try {
        const res = await saveDraft(examId, version, questions);
        if (res.ok) {
          useDraftStore.getState().markSaved(res.version, revision);
          setStatus(useDraftStore.getState().revision === revision ? "saved" : "dirty");
        } else {
          setStatus(res.code === "CONFLICT" ? "conflict" : res.code === "LOCKED" ? "locked" : "error");
        }
      } catch { setStatus("error"); }
      finally { inFlight.current = null; }
    })();
    return inFlight.current;
  }, [examId]);

  const revision = useDraftStore((s) => s.revision);
  const savedRevision = useDraftStore((s) => s.savedRevision);

  useEffect(() => {
    if (revision === savedRevision) return;
    if (statusRef.current === "conflict" || statusRef.current === "locked") return;
    if (statusRef.current !== "saving") setStatus("dirty");
    const t = setTimeout(save, 1500);
    return () => clearTimeout(t);
  }, [revision, savedRevision, save]);

  useEffect(() => {   // warn before leaving with unsaved edits
    const h = (e: BeforeUnloadEvent) => {
      const s = useDraftStore.getState();
      if (s.revision !== s.savedRevision) e.preventDefault();
    };
    window.addEventListener("beforeunload", h);
    return () => window.removeEventListener("beforeunload", h);
  }, []);

  // used by Publish: save until nothing is pending
  const flush = useCallback(async () => {
    for (let i = 0; i < 3; i++) {
      await save();
      const s = useDraftStore.getState();
      if (s.revision === s.savedRevision) return true;
    }
    return false;
  }, [save]);

  return { status, save, flush };
}

3. Building the paper: src/lib/exam/paper.ts
Your imported exams are structured: directions, case studies, and 15 cloze blanks sharing one passage. Naive shuffling would break them, so:

Questions sharing a passage stay together as one unit.
Shuffling happens only within a section (consecutive questions with the same directions). Sections keep their order.
Options aren't shuffled when they refer to each other by position or as a set, such as "Wala sa nabanggit" or "A at B". Your AP 9 #20 has one, so a shuffled "none of the above" would be wrong.
ts
import { randomInt } from "node:crypto";
import type { Layout } from "@/lib/db/schema";

const ANCHOR = /(all|none|both) of the above|wala sa nabanggit|lahat ng nabanggit|parehong|\b[A-F]\s*(and|at|&|,)\s*[A-F]\b/i;
export const keepsOptionOrder = (opts: string[]) => opts.some((o) => ANCHOR.test(o));

function shuffle<T>(arr: T[]): T[] {
  const a = [...arr];
  for (let i = a.length - 1; i > 0; i--) { const j = randomInt(i + 1); [a[i], a[j]] = [a[j], a[i]]; }
  return a;
}

export function makeLayout(exam: { shuffleQuestions: boolean; shuffleOptions: boolean }, qs: QuestionRow[]): Layout {
  const units: QuestionRow[][] = [];
  for (const q of qs) {
    const last = units.at(-1);
    if (q.context && last && last[0].context === q.context) last.push(q); else units.push([q]);
  }
  const sections: QuestionRow[][][] = [];
  for (const u of units) {
    const last = sections.at(-1);
    if (last && (last[0][0].instructions ?? "") === (u[0].instructions ?? "")) last.push(u); else sections.push([u]);
  }
  const order = sections.flatMap((s) => (exam.shuffleQuestions ? shuffle(s) : s).flat()).map((q) => q.id);

  const options: Record<string, number[]> = {};
  for (const q of qs) if (q.type === "multiple_choice" && q.options) {
    const idx = q.options.map((_, i) => i);
    options[q.id] = exam.shuffleOptions && !keepsOptionOrder(q.options) ? shuffle(idx) : idx;
  }
  return { order, options };
}

export type StudentQuestion = {
  id: string; number: number; type: "multiple_choice" | "true_false" | "identification" | "essay";
  prompt: string; options: string[] | null; points: number;
  context: string | null; instructions: string | null; underlined: string | null;
};

// explicit allow-list: never spread the DB row into the response
export function buildPaper(qs: QuestionRow[], layout: Layout): StudentQuestion[] {
  const byId = new Map(qs.map((q) => [q.id, q]));
  return layout.order.flatMap((id, i) => {
    const q = byId.get(id);
    if (!q) return [];
    const perm = layout.options[id];
    return [{
      id: q.id, number: i + 1, type: q.type, prompt: q.prompt,
      options: q.options && perm ? perm.map((k) => q.options![k]) : null,
      points: Number(q.points), context: q.context, instructions: q.instructions, underlined: q.underlined,
    }];
  });
}
Question numbers shown to students follow the shuffled order, so shuffling doesn't leak the original numbering.

export async function startSession(examId: string, consent: boolean) {
  const { user } = await requireRole(["student"]);
  const exam = await db.query.exams.findFirst({ where: eq(exams.id, examId) });
  if (!exam || availability(exam) !== "open") return FALLBACK;
  if (exam.requireCamera && !consent) return { ok: false, code: "CONSENT_REQUIRED" } as const;

  const existing = await findSession(examId, user.id);
  if (existing) return existing.status === "submitted"
    ? ({ ok: false, code: "ALREADY_SUBMITTED" } as const)
    : ({ ok: true, sessionId: existing.id } as const);                          // resume

  if (!qs.length) return { ok: false, code: "EMPTY" } as const;

  const now = new Date();
  const byDuration = new Date(now.getTime() + exam.durationMinutes * 60_000);
  const deadline = exam.scheduledEnd && exam.scheduledEnd < byDuration ? exam.scheduledEnd : byDuration;

  const [row] = await db.insert(examSessions).values({
    examId, studentId: user.id, deadlineAt: deadline, layout: makeLayout(exam, qs),
    consentAt: consent ? now : null, consentVersion: consent ? CONSENT_VERSION : null,

async function upsertAnswers(s: SessionRow, input: unknown) {
  const parsed = batchSchema.safeParse(input);

export async function saveAnswers(sessionId: string, input: unknown) {   // also serves as the clock heartbeat with []
  const { user } = await requireRole(["student"]);
  const s = await ownSession(sessionId, user.id);
  if (s.status !== "in_progress") return { ok: false, code: "SUBMITTED" } as const;
  if (Date.now() > s.deadlineAt.getTime() + GRACE_MS) {
    await finalizeSession(s.id, "timeout");
    return { ok: false, code: "EXPIRED" } as const;
  }
  if (!(await upsertAnswers(s, input))) return { ok: false, code: "INVALID" } as const;
  return { ok: true, serverTime: new Date().toISOString(), deadlineAt: s.deadlineAt.toISOString() } as const;
}

export async function submitSession(sessionId: string, finalAnswers?: unknown) {
  const { user } = await requireRole(["student"]);
  const s = await ownSession(sessionId, user.id);
  const late = Date.now() > s.deadlineAt.getTime();
  if (s.status === "in_progress") {
    if (finalAnswers && Date.now() <= s.deadlineAt.getTime() + GRACE_MS) await upsertAnswers(s, finalAnswers);
    await finalizeSession(s.id, late ? "timeout" : "student");
  }
  const fresh = await ownSession(sessionId, user.id);
  const exam = await db.query.exams.findFirst({ where: eq(exams.id, s.examId) });
  return { ok: true,
    score: exam?.showScoreOnSubmit && fresh.fullyGraded ? { score: Number(fresh.score), max: Number(fresh.maxScore) } : null } as const;
}
Details that matter:

ownSession returns 404 for anyone but the owner, so students can't probe each other's session ids.
Submit is idempotent. finalizeSession uses an UPDATE … WHERE status='in_progress' RETURNING, so a double-click or a timer-plus-click race finalizes once.
Timeout submits are stamped with the deadline, not the moment the server noticed: submittedAt = LEAST(now(), deadline_at).
Lazy finalization (finalizeIfExpired) runs on getPaper, saveAnswers, and when the teacher opens the results page. Sessions whose owner closed the tab therefore still get graded without a background job.

export async function finalizeSession(sessionId: string, reason: "student" | "timeout") {
  await db.update(examSessions).set({
    status: "submitted", submitReason: reason,
    submittedAt: reason === "timeout" ? sql`LEAST(now(), ${examSessions.deadlineAt})` : sql`now()`,
  }).where(and(eq(examSessions.id, sessionId), eq(examSessions.status, "in_progress")));

export async function finalizeIfExpired(s: SessionRow) {
  if (s.status === "in_progress" && Date.now() > s.deadlineAt.getTime() + 10_000) {
    await finalizeSession(s.id, "timeout");
    return (await db.query.examSessions.findFirst({ where: eq(examSessions.id, s.id) }))!;
  }
  return s;
}

export const normalize = (s: string) =>
  s.normalize("NFKC").toLowerCase().normalize("NFD").replace(/\p{M}+/gu, "")
   .replace(/[.'’"“”,;:!?()]/g, "")          // drop: "R.A." -> "ra"
   .replace(/[-_/]+/g, " ")                  // treat: "top-down" == "top down"
   .replace(/\s+/g, " ").trim();

export function isCorrect(q: { type: string; answers: string[] }, text: string | null): boolean {
  if (!text?.trim()) return false;
  const t = normalize(text);
  if (q.type === "multiple_choice" || q.type === "true_false") return normalize(q.answers[0] ?? "") === t;
  return q.answers.some((a) => normalize(a) === t);           // identification (incl. "T"/"Tama" for modified T/F)
}

export async function gradeSession(sessionId: string) {
  const s = await db.query.examSessions.findFirst({ where: eq(examSessions.id, sessionId) });
  if (!s || s.status !== "submitted") return;
  const qs = await db.select().from(questions).where(eq(questions.examId, s.examId));
  const ans = await db.select().from(studentAnswers).where(eq(studentAnswers.sessionId, sessionId));
  const byQ = new Map(ans.map((a) => [a.questionId, a]));

  let score = 0, max = 0, pending = false;
  const autoRows: (typeof studentAnswers.$inferInsert)[] = [];
  for (const q of qs) {
    const pts = Number(q.points); max += pts;
    const a = byQ.get(q.id);
    if (a?.manualGrade) { score += Number(a.pointsAwarded ?? 0); continue; }   // teacher decision wins
    if (q.type === "essay") { pending = true; continue; }
    const ok = isCorrect({ type: q.type, answers: q.answers }, a?.answerText ?? null);
    if (ok) score += pts;
    autoRows.push({ sessionId, questionId: q.id, answerText: a?.answerText ?? null,
                    isCorrect: ok, pointsAwarded: String(ok ? pts : 0) });
  }
  if (autoRows.length) await db.insert(studentAnswers).values(autoRows).onConflictDoUpdate({
    target: [studentAnswers.sessionId, studentAnswers.questionId],
    set: { isCorrect: sql`excluded.is_correct`, pointsAwarded: sql`excluded.points_awarded` },
    setWhere: sql`${studentAnswers.manualGrade} = false`,
  });
  await db.update(examSessions).set({ score: String(score), maxScore: String(max), gradedAt: sql`now()`, fullyGraded: !pending })
    .where(eq(examSessions.id, sessionId));
}
gradeSession can be re-run safely, so if a write fails midway, the results page calls it for any submitted session with gradedAt null. Every question gets an answer row (including blanks), so the teacher's review page shows a complete list.

ts
export function useAnswerSync(sessionId: string, onFinished: () => void) {
  const [status, setStatus] = useState<"saved" | "saving" | "offline">("saved");
  const timer = useRef<ReturnType<typeof setTimeout>>();
  const busy = useRef(false);
  const backoff = useRef(2000);

  const flush = useCallback(async () => {
    if (busy.current) return;
    busy.current = true; setStatus("saving");
    try {
      while (true) {
        const pending = await localDb.answers.where("[sessionId+synced]").equals([sessionId, 0]).limit(100).toArray();
        if (!pending.length) break;
        const res = await saveAnswers(sessionId, pending.map(({ questionId, text, clientTs }) => ({ questionId, text, clientTs })));
        if (!res.ok) { if (res.code === "EXPIRED" || res.code === "SUBMITTED") return onFinished(); throw new Error(res.code); }
        await localDb.transaction("rw", localDb.answers, async () => {
          for (const p of pending) {                                   // mark synced only if not edited meanwhile
            const cur = await localDb.answers.get([p.sessionId, p.questionId]);
            if (cur && cur.clientTs === p.clientTs) await localDb.answers.update([p.sessionId, p.questionId], { synced: 1 });
          }
        });
      }
      backoff.current = 2000; setStatus("saved");
    } catch {
      setStatus("offline");
      timer.current = setTimeout(flush, backoff.current);
      backoff.current = Math.min(backoff.current * 2, 30_000);
    } finally { busy.current = false; }
  }, [sessionId, onFinished]);

  const setAnswer = useCallback(async (questionId: string, text: string, immediate = false) => {
    await localDb.answers.put({ sessionId, questionId, text, clientTs: Date.now(), synced: 0 });
    clearTimeout(timer.current);
    timer.current = setTimeout(flush, immediate ? 150 : 900);          // radio clicks: immediate; typing: debounced
  }, [sessionId, flush]);

  useEffect(() => {
    const on = () => flush();
    const vis = () => { if (document.visibilityState === "hidden") flush(); };
    window.addEventListener("online", on); document.addEventListener("visibilitychange", vis);
    return () => { window.removeEventListener("online", on); document.removeEventListener("visibilitychange", vis); };
  }, [flush]);

  const unsynced = useLiveQuery(() => localDb.answers.where("[sessionId+synced]").equals([sessionId, 0]).count(), [sessionId], 0);
  return { status, unsynced, setAnswer, flush };
}

0. Principles and decisions
Your original doc calls these "violations", but browser events can't prove cheating. A notification popup blurs the window, Esc exits fullscreen, and a laptop lid closing stops everything. Here is how I handled that:

Log everything, judge nothing. No automatic failing, locking, or submitting. The system produces evidence and a transparent review priority, and the teacher decides.
Server classifies severity. The client only reports what happened. It can't downgrade its own severity.
Students are told. The consent screen lists what is recorded, and a discreet message appears after each event, so students see what a teacher will see.
Privacy-minimal. Paste events record the pasted length, never the content, because a clipboard may hold passwords or private messages.
Honest labels. F12 and Ctrl+Shift+I are recorded as "DevTools shortcut pressed", because browsers give no reliable way to know whether DevTools actually opened. That's why I'm dropping DEVTOOLS_ATTEMPT from the original enum.
A tamper signal that doesn't depend on the client's honesty: the server watches for gaps in heartbeats. A cheater can disable event listeners, but stopping heartbeats is visible.
Two new per-exam settings (add as Switch fields in wizard step 1, in an "Integrity" card, with requireCamera and showScoreOnSubmit):

enforceFullscreen (default on). This also fixes the iPhone problem from M6: turn it off and phones can take the exam, with events still logged.
restrictInput (default off). Blocks copy/cut/paste, right-click, and print/save/view-source shortcuts. The attempt is still logged.

Classification and event schema (src/lib/exam/classify.ts, no "use server"):

export const CLIENT_KINDS = ["TAB_SWITCH", "WINDOW_BLUR", "FULLSCREEN_EXIT", "PASTE", "COPY_CUT",
  "CONTEXT_MENU", "SHORTCUT_ATTEMPT", "OFFLINE", "SESSION_RESUMED"] as const;

export function classify(kind: string, durationMs = 0, d: Record<string, unknown> = {}): "info" | "warning" | "critical" {
  switch (kind) {
    case "TAB_SWITCH":       return durationMs >= 60_000 ? "critical" : "warning";
    case "WINDOW_BLUR":      return durationMs >= 10_000 ? "warning" : "info";
    case "FULLSCREEN_EXIT":  return d.countdownExpired || durationMs >= 30_000 ? "critical" : "warning";
    case "PASTE":            return Number(d.length ?? 0) >= 30 ? "warning" : "info";
    case "SHORTCUT_ATTEMPT": return ["F12", "Ctrl+Shift+I", "Ctrl+Shift+J", "Ctrl+Shift+C", "Ctrl+U"].includes(String(d.key)) ? "warning" : "info";
    default:                 return "info";
  }
}

const GRACE_MS = 10_000, GAP_MS = 150_000, MAX_EVENTS = 1500;

const eventSchema = z.object({
  id: z.string().uuid(),
  kind: z.enum(CLIENT_KINDS),
  clientTs: z.number().int().nonnegative(),
  durationMs: z.number().int().min(0).max(6 * 3600_000).optional(),
  details: z.record(z.string().max(30), z.union([z.string().max(60), z.number(), z.boolean(), z.null()])).optional(),
});

export async function logEvents(sessionId: string, input: unknown) {
  const { user } = await requireRole(["student"]);
  const s = await ownSession(sessionId, user.id);
  if (s.status !== "in_progress" || Date.now() > s.deadlineAt.getTime() + GRACE_MS) return { ok: false, code: "CLOSED" } as const;

  const parsed = z.array(eventSchema).max(50).safeParse(input);
  if (!parsed.success) return { ok: false, code: "INVALID" } as const;

  const [{ n }] = await db.select({ n: count() }).from(examAuditLogs).where(eq(examAuditLogs.sessionId, s.id));
  const room = Math.max(0, MAX_EVENTS - n);                       // an event storm can't bloat the table
  const rows = parsed.data.slice(0, room).map((e) => ({
    sessionId: s.id, clientEventId: e.id, kind: e.kind, clientTs: e.clientTs,
    durationMs: e.durationMs ?? null, details: e.details ?? {},
    severity: classify(e.kind, e.durationMs, e.details),          // never trusted from the client
  }));
  if (rows.length) await db.insert(examAuditLogs).values(rows)
    .onConflictDoNothing({ target: [examAuditLogs.sessionId, examAuditLogs.clientEventId] });
  return { ok: true } as const;
}

export async function heartbeat(sessionId: string, state: { visible: boolean; fullscreen: boolean; focused: boolean }) {
  const { user } = await requireRole(["student"]);
  const s = await ownSession(sessionId, user.id);
  if (s.status !== "in_progress") return { ok: false, code: "SUBMITTED" } as const;
  if (Date.now() > s.deadlineAt.getTime() + GRACE_MS) { await finalizeSession(s.id, "timeout"); return { ok: false, code: "EXPIRED" } as const; }

  const now = new Date();
  const prev = s.lastHeartbeatAt ?? s.startedAt;
  // conditional update: if two heartbeats race, only one "wins" and can log a gap
  const won = await db.update(examSessions).set({ lastHeartbeatAt: now, lastState: state })
    .where(and(eq(examSessions.id, s.id),
      s.lastHeartbeatAt ? eq(examSessions.lastHeartbeatAt, s.lastHeartbeatAt) : isNull(examSessions.lastHeartbeatAt)))
    .returning({ id: examSessions.id });

  const gap = now.getTime() - prev.getTime();
  if (won.length && gap > GAP_MS) {
    const offline = await db.select({ id: examAuditLogs.id }).from(examAuditLogs).where(and(
      eq(examAuditLogs.sessionId, s.id), eq(examAuditLogs.kind, "OFFLINE"),
      gte(examAuditLogs.clientTs, prev.getTime() - 5000), lte(examAuditLogs.clientTs, now.getTime()))).limit(1);
    await db.insert(examAuditLogs).values({
      sessionId: s.id, clientEventId: crypto.randomUUID(), kind: "HEARTBEAT_GAP", clientTs: now.getTime(),
      durationMs: gap, details: { explainedByOffline: offline.length > 0 },
      severity: offline.length ? "info" : gap > 300_000 ? "critical" : "warning",
    });
  }
  return { ok: true, serverTime: now.toISOString(), deadlineAt: s.deadlineAt.toISOString() } as const;
}
Details worth knowing:

The threshold is 150 seconds, not 90, because browsers throttle timers in background tabs (roughly once a minute), and a hidden tab shouldn't look like tampering.
Ordering on the client matters: flush queued events before sending a heartbeat. An OFFLINE event queued during a network drop then reaches the server first, so the resulting gap is correctly marked "explained by offline".
submitSession should also accept an optional finalEvents array and insert them the same way, since the last events before submit would otherwise be lost.
Review priority (src/lib/exam/priority.ts). These rules are visible to teachers, and dismissed events don't count:

ts
const AWAY = ["TAB_SWITCH", "WINDOW_BLUR", "FULLSCREEN_EXIT"];
export function reviewPriority(events: { kind: string; severity: string; durationMs: number | null; reviewStatus: string }[]) {
  const ev = events.filter((e) => e.reviewStatus !== "dismissed");
  const n = (k: string) => ev.filter((e) => e.kind === k).length;
  const awayMs = ev.filter((e) => AWAY.includes(e.kind)).reduce((s, e) => s + (e.durationMs ?? 0), 0);
  const critical = ev.filter((e) => e.severity === "critical").length;
  const bigPastes = ev.filter((e) => e.kind === "PASTE" && e.severity === "warning").length;
  const unexplainedGaps = ev.filter((e) => e.kind === "HEARTBEAT_GAP" && e.severity !== "info").length;

  const reasons: string[] = [];
  if (critical) reasons.push(`${critical} serious event${critical > 1 ? "s" : ""}`);
  if (n("TAB_SWITCH") >= 2) reasons.push(`${n("TAB_SWITCH")} tab switches`);
  if (awayMs >= 30_000) reasons.push(`${Math.round(awayMs / 1000)}s away from the exam`);
  if (bigPastes) reasons.push(`${bigPastes} large paste${bigPastes > 1 ? "s" : ""}`);
  if (unexplainedGaps) reasons.push("connection gap not explained by network loss");

  const level = critical || awayMs >= 120_000 || n("TAB_SWITCH") >= 5 || bigPastes >= 2 ? "high"
    : n("TAB_SWITCH") >= 2 || awayMs >= 30_000 || bigPastes >= 1 || unexplainedGaps ? "medium" : "low";
  return { level, reasons, awayMs };
}
It's deliberately simple and explainable: the teacher sees why a session is high, not an opaque score. The UI label is "Review priority", never "cheating likelihood".

4. The browser-side monitor: src/lib/exam/integrity-monitor.ts
ts
export type RawEvent = { id: string; kind: string; clientTs: number; durationMs?: number; details?: Record<string, string | number | boolean | null> };
type Opts = { emit: (e: RawEvent) => void; getQuestionId: () => string | null; restrictInput: boolean };

export function startIntegrityMonitor(o: Opts) {
  const ac = new AbortController();
  const { signal } = ac;
  const t0 = performance.now();
  const settled = () => performance.now() - t0 > 2500;              // ignore fullscreen-transition noise
  const last: Record<string, number> = {};
  const ev = (kind: string, extra: Partial<RawEvent> = {}, minGapMs = 0) => {
    const now = performance.now();
    if (minGapMs && last[kind] && now - last[kind] < minGapMs) return;   // throttle repeats
    last[kind] = now;
    o.emit({ id: crypto.randomUUID(), kind, clientTs: Date.now(), ...extra });
  };

  // Away tracking: hidden tab vs. unfocused-but-visible window
  let hiddenAt: number | null = null, blurAt: number | null = null;
  document.addEventListener("visibilitychange", () => {
    if (!settled()) return;
    if (document.visibilityState === "hidden") hiddenAt = performance.now();
    else if (hiddenAt !== null) {
      ev("TAB_SWITCH", { durationMs: Math.round(performance.now() - hiddenAt) });
      hiddenAt = null; blurAt = null;
    }
  }, { signal });
  window.addEventListener("blur", () => { if (settled()) blurAt = performance.now(); }, { signal });
  window.addEventListener("focus", () => {
    if (blurAt !== null && hiddenAt === null) {
      const d = Math.round(performance.now() - blurAt);
      if (d >= 1500) ev("WINDOW_BLUR", { durationMs: d });           // short blips are ignored
    }
    blurAt = null;
  }, { signal });

  // Clipboard: log length only, never content
  for (const type of ["copy", "cut", "paste"] as const) {
    document.addEventListener(type, (e) => {
      const length = type === "paste"
        ? ((e as ClipboardEvent).clipboardData?.getData("text").length ?? 0)
        : (window.getSelection()?.toString().length ?? 0);
      ev(type === "paste" ? "PASTE" : "COPY_CUT", { details: { action: type, length, questionId: o.getQuestionId() } });
      if (o.restrictInput) e.preventDefault();
    }, { signal, capture: true });
  }
  document.addEventListener("contextmenu", (e) => {
    ev("CONTEXT_MENU", {}, 5000);
    if (o.restrictInput) e.preventDefault();
  }, { signal });

  // Shortcuts: log the attempt. Blocking is best-effort and only when restrictInput is on
  const shortcut = (e: KeyboardEvent) => {
    const k = e.key.toLowerCase(), mod = e.ctrlKey || e.metaKey;
    if (e.key === "F12") return "F12";
    if (mod && e.shiftKey && ["i", "j", "c"].includes(k)) return `Ctrl+Shift+${k.toUpperCase()}`;
    if (mod && k === "u") return "Ctrl+U";
    if (mod && k === "s") return "Ctrl+S";
    if (mod && k === "p") return "Ctrl+P";
    return null;
  };
  document.addEventListener("keydown", (e) => {
    const s = shortcut(e);
    if (!s) return;
    ev("SHORTCUT_ATTEMPT", { details: { key: s } }, 2000);
    if (o.restrictInput) e.preventDefault();
  }, { signal, capture: true });
  document.addEventListener("keyup", (e) => {                        // PrintScreen only fires keyup on some systems
    if (e.key === "PrintScreen") ev("SHORTCUT_ATTEMPT", { details: { key: "PrintScreen" } }, 2000);
  }, { signal });
  window.addEventListener("beforeprint", () => ev("SHORTCUT_ATTEMPT", { details: { key: "print" } }, 2000), { signal });

  window.addEventListener("offline", () => ev("OFFLINE", { details: { online: false } }), { signal });
  return { stop: () => ac.abort() };
}

Multiple monitors can't be detected without a permission prompt (the Window Management API). I'd leave that out of a prototype.
Blur plus hidden fire together on a tab switch. The code turns that into a single TAB_SWITCH with a duration.

ts
export function useFullscreenGate(enforce: boolean, emit: (kind: string, extra: Partial<RawEvent>) => void, countdownSec = 10) {
  const [out, setOut] = useState(false);
  const [secondsLeft, setSecondsLeft] = useState(countdownSec);
  const outAt = useRef<number | null>(null);

  useEffect(() => {
    if (!enforce) return;
    const onChange = () => {
      if (!document.fullscreenElement) { outAt.current = performance.now(); setSecondsLeft(countdownSec); setOut(true); }
      else if (outAt.current !== null) {
        const ms = Math.round(performance.now() - outAt.current);
        emit("FULLSCREEN_EXIT", { durationMs: ms, details: { countdownExpired: ms >= countdownSec * 1000 } });
        outAt.current = null; setOut(false);
      }
    };
    document.addEventListener("fullscreenchange", onChange);
    return () => document.removeEventListener("fullscreenchange", onChange);
  }, [enforce, emit, countdownSec]);

  useEffect(() => {
    if (!out) return;
    const t = setInterval(() => setSecondsLeft(Math.max(0, Math.ceil(countdownSec - (performance.now() - outAt.current!) / 1000))), 250);
    return () => clearInterval(t);
  }, [out, countdownSec]);

  return { out, locked: out && secondsLeft === 0, secondsLeft,
           reenter: () => document.documentElement.requestFullscreen({ navigationUI: "hide" }).catch(() => {}) };
}

8. Tests and "done when"
Unit tests:

classify: the thresholds (a 59 s versus 60 s tab switch, a 29 vs 30-char paste, F12 versus Ctrl+S).
reviewPriority: each rule triggers its level and reason, dismissed events don't count, and an empty log is low.
Monitor (jsdom, dispatching events): a hidden-then-visible pair produces one TAB_SWITCH with a duration, a blur under 1.5 s produces nothing, events in the first 2.5 s are ignored, repeated context-menu clicks are throttled, and a paste event records length only.
Server, against a test database: the same clientEventId twice yields one row, the cap stops at 1500, another student's session is refused, an oversized details value is rejected, and two concurrent heartbeats log one gap, not two. A gap with an overlapping OFFLINE event is info and marked explained.
A student can't call reviewEvent or setSessionOutcome.
Real-browser behaviors (fullscreen, tab focus) are flaky in headless tests, so cover them with a manual checklist.

Done when:

Switching tabs logs one TAB_SWITCH with its duration. Alt-tabbing logs a WINDOW_BLUR after 1.5 s, and a brief notification popup logs nothing or at most an info event.
Exiting fullscreen shows a 10-second countdown. Returning in time logs a warning. Not returning hides the exam and disables input until the student clicks back in, then logs a critical event. The exam timer never pauses.
Reloading mid-exam requires re-entering fullscreen, logs an info-level SESSION_RESUMED, and logs no violation.
Pasting 200 characters logs the length only. Check the database and confirm no pasted text is stored. With restrictInput on, the paste is blocked but still logged.
F12 and Ctrl+Shift+I are logged as "shortcut pressed". The UI never says DevTools was opened.
Turning the network off for 3 minutes queues events locally, sends them on reconnect, and shows the connection gap as "explained by network loss".
Closing the laptop lid for 5 minutes produces an unexplained gap event after wake.
The teacher sees the priority with reasons, dismisses an event with a note, and the priority recalculates. A student account can't reach any of this.
The purge route returns 401 without the secret and deletes only events of submitted sessions older than the retention window.
A flood of 5,000 events results in at most 1,500 stored rows.
What this layer can and can't tell you: it reliably shows that the student left the exam window and for how long, whether they pasted large text, and whether the exam client went silent. It cannot see a second device, a phone under the desk, or another person in the room. That's what camera analysis in M9 partly addresses, and even then only partly.
